WHERE IS THE KNEE? The block above jumps from 64 KiB to 1 MiB and shows no
difference, while the 8 KiB a clamped container gives costs 10x. So the cost is
NOT the number of round trips -- it is whether the pipe holds enough for the
writer and the reader to run at the same time instead of taking turns. This
sweep is what says where that starts, and therefore what an ASSURED minimum
pipe size has to be. Reader chunk is 32 KiB throughout.

DOES A 2 MiB HUGE PAGE HELP? A pipe's capacity is a ring of slots holding ONE
PAGE each, so the question is whether backing the SOURCE with huge pages lets
a slot carry 2 MiB instead of 4 KiB. If it did, the round-trip count for a given
pipe size would collapse by 512x. Watch the round trips, not the time.
